Antigravity Manager 日涨135星，4类额度同屏

同一个人维护个人项目和团队项目，切错账号才发现刚才那轮任务落进了另一套配额。Antigravity Manager 把当前账号、各类模型余量和刷新时间摆到桌面窗口。北京时间 11 月 26 日午班截榜时，它排在 GitHub Trending Rust 日榜第 6，累计 34,053 星，页面显示今日新增 135 星。

要点速览

  • 桌面端用 Tauri v2、Rust 和 React，仓库文档提供 Windows、macOS、Linux 安装入口。
  • 官方总览列出 Gemini Pro、Gemini Flash、Claude、Gemini Image 四组余量。
  • 项目还做了协议转换和请求路由。第一次试用，可以从单账号、单窗口的额度管理开始。
  • 仓库标注 CC BY-NC-SA 4.0。团队部署、二次分发与商业场景先查授权。

做长任务前，给自己留一眼全局

模型工具的反馈通常很局部。某个会话停了，你才回到账号页确认余量或刷新时间；换到另一个工作空间，窗口里可能留着不同身份。这个项目的直接卖点，是把身份与当前状态挨着摆，让用户在提交长请求之前知道自己在哪个环境里。

图片来源：Antigravity Manager 官方仓库 README，2026-11-26 查阅。

项目的总览把当前账号和多类模型余量放在同个页面。Gemini Pro 与 Flash 是分别看的组，Claude 与 Gemini Image 也各有位置。做文档摘要、代码任务或出图时，先认准准备调用的那一组；只看总览里最显眼的一条进度条，很容易把不相干的池子一起算进去。

剩余额度最好与最后更新时间一起阅读。别人同时使用团队账号，或者上游状态才发生变化，桌面窗口早先抓到的数字可能已经过时。开长任务前回到上游正常入口确认一次，会比盯着旧百分比猜要可靠。

总览负责扫一眼，账号列表负责找身份

项目有总览与账号列表两个层级。总览让人迅速知道当前选中谁、余量还剩多大；列表则能并排看多份状态。文档写到列表和网格视图，以及对 403 权限异常的标识。熟悉的账号若突然进了异常状态，先从授权与工作空间归属查起。

图片来源：Antigravity Manager 官方仓库 README，2026-11-26 查阅。

分清个人项目与团队项目，建议把这两边的入口明确地留在原服务中。桌面视图可以帮助你看身份，数据的访问范围仍取决于上游、组织设置和实际授权。尤其是客户代码或内部文档，先确认公司允许第三方客户端接触相应账号。

看懂桌面端和网关的分工

仓库把这套工具称为桌面管理与协议代理系统。就桌面端而言，Tauri 承载跨平台壳，React 提供交互画面，Rust 处理后端。仓库公开的架构图还把请求入口、模型路由、请求映射与响应映射分开画。

路由是这套工具容易被忽略的一层。客户端填写的模型名与上游实际处理请求的模型，可以经过映射。调试模型输出差异时，应同时记录客户端选择的名称、上游实际名称和客户端版本。否则两次看起来一样的提问，实际可能没有落到同一种模型。

安装完成后先理解桌面界面即可。代理层意味着有另一条数据路径，涉及凭据和请求内容，也可能受上游平台与组织规则约束。日常用量查询与服务接入可以分开评估，团队成员也更容易明确自己在使用哪条路径。

图片来源：Antigravity Manager 官方仓库 README，2026-11-26 查阅。

桌面信息也有取舍。四组余量适合快速决定现在开哪个任务，但组名、可用模型和重置时间会受上游调整影响。需要预算金额或团队用量明细时，仍应回到对应平台的账单和用量页面。

这个区分在交接时尤其实用。把当前账号的用途写清楚，再附上团队认可的原生入口。这样换电脑或者桌面应用停更时，同事还知道应该从哪个工作空间接着做。

第一次试用，就带着一个明确任务来

  1. 打开官方 Releases，按系统和芯片架构选包。README 提供 macOS 的 DMG、Windows 安装包及 Linux 的 DEB 或 AppImage 等入口。下载时核对仓库所有者和发布页。
  2. 只添加一个有明确授权的测试账号，通过产品支持的授权流程进入总览。记下当前身份与刷新时间，再打开账号列表，熟悉两个页面的分工。
  3. 在服务原生客户端用这个身份完成一个日常小任务，回来刷新桌面总览。把你实际选择的模型组和面板里的分组对上，余量可能因计量和刷新节奏暂时保持原样。
  4. 用完检查账号是否还需要留在第三方工具里。试用结束可以退出测试身份，并在上游账号页面核对授权。团队长期使用前，把允许接入的账号类型和可提交的数据写清楚。

这套流程适合原本要在多个页面来回确认账号的开发者。如果你只用一个账号且上游用量页已经顺手，多一个桌面窗口带来的收益会少很多。迁移越多账号，管理凭据、组织授权和客户端更新的责任也随之增加。

Antigravity Manager 最直观的收益，是开工前能在一个窗口确认当前身份、模型组和余量，把原来散在几个页面的信息带回手边。
